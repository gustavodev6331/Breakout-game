# Breakout Game

A classic Breakout arcade game built with Python and Turtle. Control the paddle to bounce the ball, destroy all the bricks, and earn points without letting the ball fall off the screen.

## Features

* **Paddle Controls:** Move the paddle left and right using the arrow keys.
* **Ball Physics:** Bounce the ball off the walls, paddle, and bricks.
* **Brick Destruction:** Destroy bricks by hitting them with the ball.
* **Scoreboard:** Earn 10 points for every brick destroyed.
* **Win and Lose Conditions:** Complete the level by destroying all bricks or lose if the ball falls below the paddle.
* **Final Score:** Display your result and final score at the end of the game.

## Technologies Used

* Python
* Turtle Graphics

## How to Play

1. Clone this repository.
2. Make sure Python 3 is installed.
3. Run `main.py`.
4. Use the **Left** and **Right arrow keys** to control the paddle.
5. Bounce the ball off the paddle to destroy all the bricks.
6. Try to achieve the highest score possible!

## Installation

Clone the repository:

```bash
git clone https://github.com/gustavodev6331/breakout-game.git
cd breakout-game
```

Run the game:

```bash
python3 main.py
```
